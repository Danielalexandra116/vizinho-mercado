COMO VISUALIZAR NO VS CODE
1. Extraia este ZIP.
2. Abra a pasta vizinho-mercado no VS Code.
3. Instale a extensão Live Server.
4. Abra index.html.
5. Clique com o botão direito no arquivo e escolha "Open with Live Server".
